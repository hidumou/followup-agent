# 12 界面设计规范（控制台）

适用于本机网页控制台（自 M0 起分阶段实现，M5 完善与验收）。CLI 遵循第 15 节的视觉约定。颜色与尺寸的唯一来源是 `docs/assets/design-tokens.css`，组件里不得硬编码颜色。

## 1. 设计目标与风格

这是一个**审阅型运营工具**：核心动作是阅读、判断、批准或拒绝，而不是浏览内容。设计服务于三件事：

1. 读得清：文本、diff、证据一目了然。
2. 判得准：状态、风险、后果清晰，危险动作有明确区分。
3. 不打扰：克制、安静，没有装饰性元素。

风格关键词：**中性、克制、清晰、信息密度适中**。
- 大面积使用中性灰蓝，色彩只用于表达状态和主操作。
- 扁平：不使用渐变、毛玻璃、发光；阴影只用于浮层。
- 一个主色（靛蓝），一套语义色（成功、警告、危险）。
- 同一屏最多一个主按钮。

## 2. 布局

### 应用框架

```
┌ 顶栏 48px ────────────────────────────────────────────────┐
│ 名称   发送模式标签   playbook 版本   预算   主题切换        │
├ 左导航 220px ┬ 主区 ─────────────────────────────────────┤
│ 工作台        │ 页头：标题 + 说明（左）  主操作（右）       │
│ 回访任务      │ ───────────────────────────────────────── │
│ 草稿审批 (n)  │ 内容区（最大宽度 1200px，居中）             │
│ 回复与洞察    │                                           │
│ 报告          │                                           │
│ Playbook      │                                           │
│ 建议 (n)      │                                           │
│ 运行与评估    │                                           │
│ 设置          │                                           │
└──────────────┴───────────────────────────────────────────┘
```

### 尺寸与网格

| 项目 | 规格 |
|---|---|
| 顶栏高度 | 48px，固定 |
| 左导航 | 220px；视口窄于 1280px 时折叠为 64px 仅图标，悬停显示名称 |
| 内容最大宽度 | 1200px；阅读型页面（报告、建议详情）单栏 760px |
| 审批页 | 左侧队列 320px，右侧详情自适应；视口小于 1100px 时队列改为顶部可折叠列表 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px 阶梯，组件内部 8 或 12，区块之间 24 |
| 表格行高 | 44px，表头固定，悬停高亮，不使用斑马纹 |
| 最小支持宽度 | 1024px。仅桌面使用，不做手机适配 |

### 页面骨架约定
- 每页：页头（标题、一句话说明、右侧主操作）→ 可选筛选栏 → 内容。
- 列表页：筛选栏 + 表格或队列，空状态居中。
- 详情页：顶部摘要条（对象 ID、状态、版本）+ 主体 + 右侧辅助信息（上下文）。
- 审阅页（审批、建议）：左列表、右详情，操作按钮固定在详情底部。

## 3. 主题色

### 基础与主色

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | #F7F8FA | #0F1319 | 页面背景 |
| `--surface` | #FFFFFF | #161B22 | 卡片、面板、输入框 |
| `--surface-subtle` | #F1F3F6 | #1D242D | 次级区域、表头、中性徽标 |
| `--border` | #E2E6EC | #2A333F | 默认边框、分割线 |
| `--border-strong` | #CBD2DC | #3A4553 | 强调边框、悬停 |
| `--text` | #1B2430 | #E6EAF0 | 正文 |
| `--text-muted` | #5B6675 | #A5AFBD | 次要文字 |
| `--text-faint` | #8A94A3 | #7C8796 | 占位符、禁用提示，不用于重要信息 |
| `--primary` | #3B5BDB | #8FA3F7 | 主按钮、链接、选中、焦点 |
| `--primary-subtle` | #EEF1FD | #1E2540 | 选中背景、主色徽标底 |

### 语义色

| 语义 | 前景（浅/深） | 底色（浅/深） | 用途 |
|---|---|---|---|
| 成功 | #1A7F52 / #4CC38A | #E6F4EC / #12261D | 已发送、护栏通过、新增 diff |
| 警告 | #9A5B00 / #E0A93B | #FFF4DB / #2A2110 | 需注意、live 白名单模式、回归部分变差 |
| 危险 | #C93A3A / #F27A7A | #FCE9E9 / #2D1717 | 失败、拒绝、live 模式、删除 diff |

### 使用规则
- 颜色按含义使用，不按顺序轮换；一屏里彩色元素尽量少。
- 主色用于一个主操作；同屏其他按钮用次级或幽灵样式。
- 彩色底上的文字使用同色系的前景色，不用纯黑或灰。
- 状态**不能只靠颜色**表达，必须配图标和文字。
- 颜色已按 WCAG AA 目标选取，实现后仍须用对比度工具校验正文与按钮文字；`--text-faint` 对比度偏低，只用于次要提示。

## 4. 状态与语义映射

### 发送模式（顶栏常驻）

| 模式 | 样式 | 含义 |
|---|---|---|
| `DRY-RUN` | 中性（`surface-subtle` 底，次要文字） | 不会真实发送 |
| `LIVE · 白名单` | 警告色徽标 | 只会发给白名单邮箱 |
| `LIVE` | 危险色徽标，加粗边框 | 会真实发送给用户 |

颜色随真实后果的严重程度递增。

### 回访与草稿状态

| 状态 | 样式 | 图标 |
|---|---|---|
| 待审批 | 主色淡底 + 主色文字 | 时钟 |
| 已批准 | 中性 | 勾 |
| 已发送 | 成功 | 发送 |
| 已回复、已分析 | 成功 | 对话、勾 |
| 发送失败、运行失败、超预算 | 危险 | 警示 |
| 已拒绝、已过期、搁置、观察中 | 中性（弱） | 叉、时钟 |

### 其他语义
- 护栏结果：通过为成功色勾；失败为危险色警示并写明原因。
- 风险等级：低（中性）、中（警告）、高影响（危险，附锁或感叹图标）。
- 回归指标对比：改善用成功色并配 ↓ 或 ↑ 箭头及文字，变差用危险色，持平用中性；始终显示「前 → 后」数值。
- diff：新增行成功淡底，删除行危险淡底，并保留 `+` 与 `-` 前缀，不只靠颜色。
- 仅人工可改（受限范围）：锁图标 + 中性徽标「仅人工可改」。
- 不可信数据块（用户回复原文）：虚线边框 + 顶部固定标签「不可信数据，仅用于分析」。
- 掩码联系方式：锁图标 + 等宽字体，如 `j***@e***.com`。

## 5. 字体与排版

| 项目 | 规格 |
|---|---|
| 字体 | 系统字体栈（含 PingFang SC、微软雅黑、Noto Sans CJK），不引入在线字体 |
| 等宽 | 系统等宽栈，用于 ID、diff、掩码地址、命令 |
| 基础字号 | 14px（界面），16px（报告与长文本阅读区） |
| 字号阶梯 | 12 / 13 / 14 / 16 / 20 / 24px |
| 字重 | 400 常规、500 中等、600 强调；标题不超过 600 |
| 行高 | 界面 1.4；阅读区 1.7 |
| 数字 | 表格与指标使用等宽数字（`font-variant-numeric: tabular-nums`） |
| 标题层级 | 页面标题 20px/600；区块标题 16px/600；表头 13px/500 次要色 |
| 行宽 | 阅读区不超过 760px，避免过长行 |

## 6. 形状与层次
- 圆角：输入框、按钮 6px；卡片、面板 8px；徽标全圆角。
- 边框：1px，使用 `--border`；悬停或聚焦时提升为 `--border-strong` 或主色。
- 阴影：仅用于浮层（弹窗、菜单、提示），使用 `--shadow-popover`；页面内卡片不使用阴影。
- 层次：页面背景 → 卡片（`--surface`）→ 浮层。同屏浮层不超过两层，需要第三层时改用模态对话框。

## 7. 组件规范

| 组件 | 要点 |
|---|---|
| 按钮 | 主要（主色填充）、次级（边框）、幽灵、危险（危险色边框，确认弹层中可填充）；高 32px，紧凑 28px；禁用时在旁边或提示中说明原因，不静默禁用 |
| 徽标 / 状态标签 | 圆角胶囊，图标 + 文字，高 22px |
| 表格 | 行高 44px、表头固定、列可排序、点击行进入详情；超出显示省略并提供完整提示 |
| 队列列表 | 每项两行：主信息（用户 ID、标签）+ 预览；选中项主色淡底加左侧 2px 主色条 |
| Diff 视图 | 等宽字体，并排或行内可切换，默认行内；删除与新增行有前缀符号 |
| 时间线 | 竖线 + 节点，节点颜色按状态，时间在左、内容在右 |
| 标签页 | 下划线式，选中为主色 |
| 表单 | 标签在上，帮助文字在下，校验信息在字段下方就地显示 |
| 模态对话框 | 宽 480px，标题说明动作，正文说明后果，按钮右对齐，主要动作在右 |
| 确认弹层（危险） | 必须写出影响范围，如「将向 1 个收件人发送真实邮件」；需要输入或勾选时才能点击确认的场景见 `11` |
| 提示条（Banner） | 位于页头下方，成功、警告、危险三种，带关闭或操作 |
| Toast | 右下角，4 秒自动消失，错误类不自动消失 |
| 进度条 | 用于预算使用，超过 80% 变警告色，超过 100% 变危险色 |
| 骨架屏 | 列表与详情加载时使用，不用旋转指示器占满页面 |
| 空状态 | 一句说明 + 下一步动作，居中，不使用插画 |

### 专用组件
- `ModeBadge`：顶栏发送模式。
- `VersionChip`：显示 `v7`，可点击进入版本详情。
- `GuardrailList`：逐项显示护栏检查结果。
- `MaskedContact`：掩码联系方式。
- `UntrustedTextBlock`：不可信文本容器。
- `EvidenceExpander`：折叠的证据列表，展开显示记录链接与片段。
- `RegressionTable`：指标「前 → 后」对比。
- `DiffViewer`、`Timeline`、`BudgetBar`。

| S5 回复与洞察 | 左列表右详情；原文区使用 `UntrustedTextBlock`，默认折叠 |

## 9. 数据可视化
- 只用简单图表：条形图（原因 TopN）、折线图（按 playbook 版本的趋势）。不用饼图和 3D。
- 颜色：主色表示当前或重点，灰色表示其他，最多再加一个强调色；类别不超过 5 个。
- 直接在图上标数值与类别名，减少对图例的依赖。
- 坐标轴与网格线使用 `--border`，文字使用 `--text-muted`。
- 所有图表必须有文字摘要或表格形式的等价数据。

## 10. 图标
- 使用单一图标集，线性风格，16px（行内）与 20px（导航）。建议 Lucide 或同类开源图标，随项目分发，使用前核实许可证。
- 图标内联为 SVG，继承文字颜色；不使用 emoji。
- 纯装饰图标加 `aria-hidden`，仅图标的按钮必须有 `aria-label`。
- `10` 中线框里的 ✓、!、🔒 只是占位，实现时替换为图标。

## 11. 文案与语气
- 简洁、中性、直接；不用感叹号，不用「请」「成功地」之类的赘词。
- 按钮用动词开头：批准、拒绝、回滚、采纳；不用「确定」「提交」。
- 错误信息：说明发生了什么与下一步怎么做，一句话，不展示技术堆栈。
- 确认文案写明后果：「将以 v5 的内容创建新版本 v8」。
- 术语统一：回访任务、草稿、回复、洞察、建议、版本、护栏。
- 空状态是邀请而非道歉：「今天没有待审批的草稿」。

## 12. 反馈与动效
- 动效只用于状态过渡：淡入淡出、展开收起，时长 120 到 200ms，缓动 ease-out。
- 尊重 `prefers-reduced-motion`，令牌文件已将时长置零。
- 操作后即时反馈：按钮进入处理中状态、Toast 或就地更新；长耗时操作（如回归）显示进度与可取消。
- 不使用弹跳、闪烁、循环动画。

## 13. 可访问性与键盘操作
- 目标 WCAG AA；正文 4.5:1，大字与组件边界 3:1。
- 焦点可见：2px 主色焦点环，偏移 2px；不得去掉默认焦点样式而不替代。
- 所有功能可只用键盘完成；模态框有焦点陷阱，`Esc` 关闭。
- 页面声明 `lang="zh-CN"`；使用语义化标签与 ARIA 角色（表格、列表、对话框、状态提示）。
- 状态变化通过 `aria-live` 区域播报。
- 字号用 rem，支持浏览器缩放到 200%。

### 审批页快捷键

| 键 | 动作 |
|---|---|
| `j` / `k` | 队列下一项 / 上一项 |
| `e` | 编辑 |
| `r` | 拒绝（打开原因弹层） |
| `a` | 批准（live 模式下仍需二次确认） |
| `s` | 跳过 |
| `?` | 显示快捷键帮助 |

快捷键仅在焦点不在输入框时生效。

## 14. 深色模式
- 跟随系统，并在顶栏提供手动切换（浅、深、跟随系统），选择保存在浏览器本地。
- 令牌文件已提供两套；组件只引用令牌，不写任何深色专属覆盖。
- 深色下主色提亮、语义色提亮，底色为低饱和深色，避免大面积纯黑与纯白。
- 图表、diff、徽标在两种主题下都必须验证可读性。

## 15. CLI 视觉约定（MVP）
- 输出头部显示发送模式与 playbook 版本：`[DRY-RUN] playbook demo v7`。
- 状态用符号加文字：`✓` 成功、`!` 警告、`✗` 失败、`·` 中性；颜色可选，遵守 `NO_COLOR` 环境变量。
- 表格对齐，ID 使用等宽；长文本折行或提供 `--full`。
- 危险操作需输入 `yes` 确认，并打印影响范围。
- 交互提示统一格式：`[a]批准 [e]编辑 [r]拒绝 [s]跳过`。

## 16. 实现要求与验收清单
- [ ] 全部颜色、间距、圆角、字号来自 `design-tokens.css`，代码中无硬编码颜色。
- [ ] 浅色与深色两套主题都已检查，包含 diff、徽标、图表。
- [ ] 顶栏常驻发送模式与 playbook 版本；发送模式无任何切换入口。
- [ ] 同屏最多一个主按钮。
- [ ] 状态均有图标与文字，不只靠颜色。
- [ ] 联系方式只显示掩码；用户回复原文使用不可信数据块。
- [ ] 键盘可完成审批流程；焦点可见；对比度已用工具校验。
- [ ] 无外部资源请求（字体、图标、脚本、样式）。
- [ ] 界面与 `10` 的线框和 `11` 的交互一致，偏离处在 PR 说明里写明原因。
