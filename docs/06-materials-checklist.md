# 06 所需资料清单

状态：已提供 / 部分 / 未提供。「降级」指资料缺失时可以怎么继续。

## 已确认的信息
- 用户数据平台可通过 API 访问，API 可直接返回流失用户列表。
- 回访邮件渠道倾向 Resend（Cloudflare 发信需付费计划，不选；Gmail 配置较重，暂不用）。
- 模型：OpenAI 或火山引擎，要求框架尽量兼容多厂商。
- 总结汇报面向决策者。
- Cloudflare 为免费账号，允许放用户数据；本机可运行。
- 暂无现成的人工回访流程文档；公司对用户数据发给第三方模型的规定尚不确定。

## 安全提醒
- 样例数据必须脱敏；不要提供真实邮箱、姓名、密钥。
- 密钥只放本机 `.env`，由代码读取。
