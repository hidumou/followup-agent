# 新版 M0 对齐验收记录

日期：2026-11-11。范围以本轮用户确认和 `07` 的“新版 M0 对齐”为准。

## 实现结果

- 控制台迁入 `src/console/server` 与 `src/console/web`；Hono HTTP 层、React/Vite、CSS Modules、共享设计令牌、Lucide 图标。
- 九模块导航按阶段提供入口；工作台、逐用户回访列表/详情、已有审批、当前 Playbook、运行与定时计划可用。
- 深浅色与系统主题、本地偏好保存、键盘焦点、1024px 桌面布局。仅审批、拒绝等已有能力提前保留，后续模块不伪装为已实现。
- `core/services` 为 CLI 与 HTTP 提供共用操作和查询。人工操作与业务更新在同一 SQLite 事务中写审计；不保存令牌、联系方式或草稿正文到审计摘要。
- Host / Origin / Fetch Metadata 校验和每次启动随机会话令牌；浏览器只在内存保存令牌。旧令牌失效后不自动重放写操作。
- 新运行保存匿名上下文、分类结果及 Playbook 版本。旧记录的未知字段保持为空，界面显示“未记录”。完整版本历史仍属于 M1。
